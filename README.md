# 🥗 Nutrition Quiz App
visit: https://cpatel-nutritionapp.netlify.app/
An interactive web-based quiz application designed to help users test and improve their knowledge of nutrition through multiple-choice questions and instant feedback.

## 📖 Project Overview

The Nutrition Quiz App is an educational application that presents users with a series of nutrition-related questions. Users can navigate through questions, receive immediate feedback on their answers, and view their final score at the end of the quiz.

The application aims to promote nutrition awareness while providing an engaging learning experience.

---
## ✨ Features

- Multiple-choice nutrition questions
- Randomised question order each time the quiz starts
- Immediate feedback for correct and incorrect answers
- Displays the correct answer when a question is answered incorrectly
- Previous and Next navigation buttons
- Final score calculation and display
- Restart quiz functionality
- Responsive and user-friendly interface

## 🚀 How to Run the Project

1. Download or clone the repository:

```bash
git clone https://github.com/your-username/nutrition-quiz-app.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional software or installation is required.

---
## 🎮 How to Use

1. Click **Start Quiz**.
2. Read each nutrition question carefully.
3. Select your answer.
4. Click **Next**.
5. Receive instant feedback on your answer.
6. Continue until all questions are completed.
7. View your final score.
8. Reveiw the previous question
